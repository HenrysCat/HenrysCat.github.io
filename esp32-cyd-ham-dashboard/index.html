ESP32 CYD Ham Dashboard

Install the latest firmware onto your CYD ESP32 display.

Select the board that matches yours, then connect USB and flash. The display driver is built into each firmware, so the wrong choice will flash successfully but leave the screen blank or garbled.

The installer asks whether to erase the device first. Leave Erase device unticked to keep your callsign, locator, Wi-Fi details and other settings when upgrading. Tick it for a first-time install, or to start again from a clean slate.
