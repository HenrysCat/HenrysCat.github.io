NerdMiner Modded

Firmware for other boards, built from the same NerdMiner Modded v1.6.0 code as the tested builds (M5StickC Plus2, original look: v1.6.1).

Not tested on hardware. These builds compile, but nobody has run them on a real board for this release. They may not work, or may leave the screen blank. A full install replaces whatever is on the board. Use them at your own risk, and please report what you find, good or bad.

For the 2.8" CYD (one USB port or two), the 4.0" CYD, the LilyGO T-Display 1.14", the M5StickC Plus2 (Pulse theme), the ES3C35P (ESP32-S3, 3.5" 320x480) and the screenless ESP32-WROOM-32, use the tested builds instead.

Choose your board

Many boards share a chip, so the installer cannot tell them apart: the wrong choice can flash fine but leave the screen blank or scrambled. If that happens, pick the right board and do a full install again.

Full install (factory)

Writes the complete image for the : bootloader, partition table and firmware. Use this the first time you flash a board, when coming from a different firmware, or to start again from a clean slate.

The installer asks whether to erase the device first. Tick Erase device for a completely clean start, which clears your Wi-Fi, pool and wallet settings so you will need to set them up again.

Update firmware only

Writes just the application firmware for the and leaves the bootloader, partition table and your saved settings alone. Use this to upgrade a board that is already running NerdMiner Modded.

Don't use this on a board that has never had NerdMiner Modded (or another NerdMiner build with the same partition layout) on it. Do a full install first.

The installer asks whether to erase the device first. Leave Erase device unticked here: erasing also removes the bootloader and your settings, and the board will not start again until you do a full install.

Connect your board via USB first. The installer needs a browser with Web Serial support, such as Chrome, Edge or Brave. After flashing, connect to the NerdMinerAP Wi-Fi network to enter your Wi-Fi details and BTC address.
