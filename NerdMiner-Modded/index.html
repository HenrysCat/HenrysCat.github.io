NerdMiner Modded

Install NerdMiner Modded v1.2.1 onto your CYD (Cheap Yellow Display).

Tested on the CYD only. This firmware is built for the two boards below and has not been tested on any other board.

Choose your board

Both boards use the same chip, so the installer cannot tell them apart: the wrong choice flashes fine but leaves the screen blank or scrambled. If that happens, pick the other board and do a full install again.

Full install (factory)

Writes the complete image for the 2.8" CYD: bootloader, partition table and firmware. Use this the first time you flash a CYD, when coming from a different firmware, or to start again from a clean slate.

The installer asks whether to erase the device first. Tick Erase device for a completely clean start, which clears your Wi-Fi, pool and wallet settings so you will need to set them up again.

Update firmware only

Writes just the application firmware for the 2.8" CYD and leaves the bootloader, partition table and your saved settings alone. Use this to upgrade a CYD that is already running NerdMiner Modded.

Don't use this on a board that has never had NerdMiner Modded (or another NerdMiner build with the same partition layout) on it. Do a full install first.

Connect your CYD via USB first. The installer needs a browser with Web Serial support, such as Chrome, Edge or Brave. After flashing, connect to the NerdMinerAP Wi-Fi network to enter your Wi-Fi details and BTC address.
