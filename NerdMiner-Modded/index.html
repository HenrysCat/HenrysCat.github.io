NerdMiner Modded

Install NerdMiner Modded v1.6.0 onto your CYD (Cheap Yellow Display), LilyGO T-Display, ES3C35P or a bare ESP32-WROOM-32 board.

Tested on these boards only. This firmware has been tested on the boards below. Builds for other boards, which compile but have not been tested on hardware, are on the untested boards page.

Choose your board

The installer only checks the chip type. All of these boards except the ES3C35P use the same classic ESP32 chip, so it cannot tell them apart: the wrong choice flashes fine but leaves the screen blank, scrambled or in the wrong colours. If that happens, pick the right board and do a full install again.

Full install (factory)

Writes the complete image for the 2.8" CYD: bootloader, partition table and firmware. Use this the first time you flash a board, when coming from a different firmware, or to start again from a clean slate.

The installer asks whether to erase the device first. Tick Erase device for a completely clean start, which clears your Wi-Fi, pool and wallet settings so you will need to set them up again.

Update firmware only

Writes just the application firmware for the 2.8" CYD and leaves the bootloader, partition table and your saved settings alone. Use this to upgrade a board that is already running NerdMiner Modded.

Don't use this on a board that has never had NerdMiner Modded (or another NerdMiner build with the same partition layout) on it. Do a full install first.

The installer asks whether to erase the device first. Leave Erase device unticked here: erasing also removes the bootloader and your settings, and the board will not start again until you do a full install.

Connect your board via USB first. The installer needs a browser with Web Serial support, such as Chrome, Edge or Brave. After flashing, connect to the NerdMinerAP Wi-Fi network to enter your Wi-Fi details and BTC address.
